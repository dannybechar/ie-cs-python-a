# Audit: Unit 6 (Strings) + ministry meeting 19 (exam prep: strings and turtle) + formula sheet

Date: 2026-11-13. Read-only audit; no repo content was edited. Folder meeting numbers are authoritative (README). "m15" below always means the ministry **folder** meeting 15, never repo meeting 15 (= 6.1).

**Verdict (5 lines)**
1. Core Unit 6 topics are covered and the hours match `python-a.pdf` (p.13 goals, p.14 table: 2 theory + 6 practice h = 360 min; verified by rendering the pages).
2. Two blocking gaps against the ministry content: **negative indexes** are deliberately excluded (U6-01) although m15 teaches them and 5 of the 16 exam-prep string items (deck #1, #2, #5, #6; worksheet Q1) use them, and **no exercise builds a new string in a loop** (U6-02), which is the main pattern in the exam-prep questions.
3. The exam style (m19, formula sheet 19.2/20.5) uses `wn = turtle.Screen()`, `player = turtle.Turtle()`, `turtle.mainloop()`; the repo avoids Turtle objects and uses `turtle.done()` everywhere (U6-03). Students will meet unfamiliar code in the exam.
4. Smaller omissions (`str()`, `index`, `not in`, `+=`, optional parameters of `find`/`count`/`startswith`/`replace`, `chr`/`ord`, `isdigit` naming) fit inside the existing 360 minutes only if `banner()` and `name_card()` are demoted to optional/demo; net cost is about +5 min per meeting, offset as listed in the ledger.
5. The official formula sheet is never given to students (U6-11); meeting 19 has no repo slot and the schedule has no spare meeting (course-map: 31 needed, 26 by end of April), so exam practice must be homework with a 10-minute review (U6-10).
