# Audit: Unit 8 (functions with parameters) against the ministry Classroom program

Audited 2026-11-13. Read-only audit; no repo content was changed.

## Verdict

1. Unit 8 matches the hours in `docs/ministry-source/python-a.pdf` p.17 exactly (360 min, 90 T / 270 P) and every page citation checks out, but it omits `return`, which ministry meeting 10 teaches as a core part of "functions part B" (and which meetings 8, 12, 13 and 16 already use in their worked solutions).
2. The omission is a real authority conflict, not a slip: python-a.pdf p.17 (goals 1-2, assessment 2) says functions "שאינה מחזירה ערך", while the folder (content authority) teaches return. The repo followed the PDF. The teacher must decide; I propose a zero-sum "return-lite" (20 min).
3. Style and vocabulary differ from the folder: the folder says "פעולה" (364 uses against 7 for "פונקציה") and never says "ארגומנט"; it calls the passed value "פרמטר"; it never uses `main()` except in a menu program at meeting 14; it uses `+=` and `elif` freely.
4. The ordering problem (folder: functions at 4 and 10; repo: Unit 8) is mild: Units 1-7 already use parameterless functions that read input inside, which is exactly the folder's meeting-4 style; only parameters/return/scope arrive late, and no Unit 1-7 `.py` file defines a function with a parameter.
5. All 10 Unit 8 and 9 deck PDFs are image-only (pdftotext returns nothing), so deck text could not be machine-compared; deck findings rest on the lesson notes, which cite slide numbers, plus a visual spot check of 8.3 slides 1-6.

Authority used: folder = content, python-a.pdf = hours. Extracts are cited by file name under `docs/ministry-program/extracts/`; folder numbers are authoritative.
