- ניתן להשתמש בלולאת for במספר תצורות - הגדרת ערך התחלתי וקפיצות:
- start - ערך התחלתי למשתנה הלולאה (כולל).
- stop - ערך סופי למשתנה הלולאה (לא כולל).
- item - משתנה המייצג את מונה הלולאה (כמה פעמים הלולאה בוצעה).
- הערך בהתחלה יהיה start והלולאה תתבצע מ-start  עד stop.
- Item הוא שם של משתנה. ניתן לבחור בכל שם שנרצה.
- step - בכמה להגדיל את משתנה הלולאה. ברוב המקרים נשתמש בערך 1. 
- המשתנה חייב להיות מספר שלם; חיובי או שלילי.
