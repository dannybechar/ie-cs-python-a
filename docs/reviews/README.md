# External reviews

Records of lesson reviews by an outside reviewer (ChatGPT), one folder per review.

| Review | Lessons | Files | Outcome |
|---|---|---|---|
| [`unit2-m1-m2/`](unit2-m1-m2) | Unit 2 Meetings 1–2 | [`REVIEW-REQUEST.md`](unit2-m1-m2/REVIEW-REQUEST.md) (brief sent to the reviewer), [`REVIEW-CHANGES-v2.md`](unit2-m1-m2/REVIEW-CHANGES-v2.md) (what changed per finding) | All findings applied before the lessons were added to [`units/u2-turtle-graphics`](../../units/u2-turtle-graphics) |
| [`unit2-test/`](unit2-test) | Unit 2 test, Forms A and B | [`REVIEW-REQUEST.md`](unit2-test/REVIEW-REQUEST.md) (brief sent to the reviewer), [`REVIEW-REPORT.md`](unit2-test/REVIEW-REPORT.md) (reviewer's report), [`REVIEW-FOLLOWUP.md`](unit2-test/REVIEW-FOLLOWUP.md) (what was accepted, rejected and left open) | Valid findings applied (8 fixes). One reported key error was a false positive; open items left to the teacher |
| [`unit2-written-test/`](unit2-written-test) | Unit 2 written turtle test, Form A (time estimate) | [`REVIEW-FOLLOWUP.md`](unit2-written-test/REVIEW-FOLLOWUP.md) (findings and decisions; the request and report were chat-only) | Time and grid findings applied in revision 2; one reported grid error was a false positive; pilot timing left open |

The review requests list file names as they were in the review folder, e.g. `m1-lesson-notes.md`. The current versions of those files are in the unit's folder under `units/`.

For `unit2-test/`, the files the reviewer saw (`Version_A_student_test.md` and the like) were plain-text exports of the question data in [`tools/unit-test-builder/`](../../tools/unit-test-builder/README.md) and are not committed. The tests themselves are in [`units/u2-turtle-graphics`](../../units/u2-turtle-graphics/README.md#unit-2-test).
