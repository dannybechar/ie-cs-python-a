יחידה 0.1 – סביבת עבודה

כיתה ז׳ · Python A · מכינים את המחשב לפייתון

Install → Open → Check → Save → Reopen

IMPORTANT

שפת Python היא השפה שנלמד. Thonny הוא הכלי שבו נכתוב ונריץ אותה. כשמתקינים את Thonny, מקבלים גם את Python.

1. מורידים רק מהאתר הרשמי

היכנסו לאתר thonny.org. בדקו בשורת הכתובת שזה באמת האתר הזה.

אל תלחצו על כפתורי "Download" של פרסומות באתרים אחרים.

2. מתקינים

NOTE

Tool Note – Thonny

  1. באתר, בחרו את קובץ ההתקנה ל-Windows (הקובץ שמסתיים ב-x64.exe).
  2. הריצו את הקובץ שירד.
  3. השאירו את כל ברירות המחדל ולחצו Next עד הסוף.
  4. פתחו את Thonny מתפריט Start.
  5. אם Thonny שואל על שפה והגדרות: בחרו English ו-Standard.

WARNING

אם Windows מציג אזהרה ("Windows protected your PC"), עצרו וקראו למורה.

סיימתם לפני כולם? עזרו לחבר או לחברה במילים בלבד, בלי לגעת בעכבר שלהם.

3. מכירים את החלון

חלק בשביל מה
עורך (למעלה) כאן כותבים את התוכנית
חלון Shell (למטה) כאן מופיע הפלט
כפתור Run (▶ ירוק, או F5) מריץ את הקובץ שבעורך
כפתור Stop (■ אדום) עוצר תוכנית שרצה

4. תיקיית הקורס

צרו תיקייה בשם G7-Python בתוך Documents.

כל הקבצים של הקורס יישמרו בתיקייה הזו, כל השנה.

העתיקו לתיקייה את הקובץ EnvironmentCheck.py שהמורה נתן.

TIP

כללים לשמות קבצים

  • אותיות באנגלית, מספרים ו-_ בלבד. בלי רווחים ובלי עברית.
  • תמיד מסתיים ב-.py.
  • אסור לקרוא לקובץ בשם turtle.py, random.py או math.py.

5. בדיקת הסביבה

פתחו ב-Thonny את EnvironmentCheck.py והריצו.

אם הכול תקין, יופיע הפלט הזה, ובחלון נוסף ריבוע כחול עם המילה Ready:

Python version: 3.x.y
OK   Python 3
OK   math
OK   random
OK   turtle
Opening the drawing window...
All done. Close the drawing window to finish.

בסוף, סגרו את חלון הציור.

עוד לא צריך להבין את הקוד. עד סוף השנה תבינו את רובו.

6. שומרים, סוגרים ופותחים שוב

NOTE

Tool Note – Thonny

  1. בתפריט File → Save As, שמרו בתיקיית הקורס בשם G7_U0_Check_<Name>.py.
  2. סגרו את Thonny לגמרי.
  3. פתחו את Thonny שוב, ובתפריט File → Open פתחו את הקובץ מתיקיית הקורס.
  4. הריצו אותו שוב.

7. שיעורי בית: מתקינים גם בבית

התקינו את Thonny במחשב בבית באותה דרך, והריצו שם את EnvironmentCheck.py.

יש גם גרסאות ל-Mac ול-Linux באתר thonny.org. אין מחשב בבית, או שאי אפשר להתקין? ספרו למורה: אפשר גם לעבוד בסביבה באינטרנט.

בדיקת סיום: אני יכול/ה לפתוח את Thonny, להריץ את בדיקת הסביבה ולקבל OK בכל השורות, ולמצוא את הקובץ ששמרתי בתיקיית הקורס.
