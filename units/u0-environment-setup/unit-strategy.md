# Unit 0 — Environment Setup

**School addition — one 90-minute lab meeting, outside the official 60 hours.**
Source: [`python-a.pdf`](../../docs/ministry-source/python-a.pdf) Chapter 1 (p.6), performance goals 1–2:
"the student will know how to install the working environment" and "…how to run the working environment".
Chapter 1 also says the environment is taught "in the lab, with an explanation of installing the environment",
and that the environment itself should not get special importance. Unit 1 then takes over with
open → run → save and first code.

**Build status:** ⚠️ partial — lesson notes, lab brief and check script are built; slides (`m1-slides-he.md`) are pending.

## Why a separate meeting
Unit 1's 90 minutes are fully used by output, comments and a first function. Installing the tool,
learning where files live and proving the setup works would squeeze that lesson, so it gets its own
first lab meeting.

## Scope
- What Python is vs. what Thonny is (the language vs. the tool we write it in).
- Downloading safely, from the official site only.
- Installing Thonny (it includes Python 3, so nothing else is needed).
- A first look at Thonny: editor, Shell, Run, Stop.
- The course folder: where files are saved, and file-naming rules.
- Running a provided check file (`EnvironmentCheck.py`) to prove Python, `math`, `random` and `turtle` work.
- Save As, close, reopen: proving the file really is saved.
- Installing again at home.

Out of scope: writing code. `print()`, comments and functions start in Unit 1.

## Meeting breakdown
| Meeting | Format | Content |
|---|---|---|
| m1 | Lab + Lab (short intro) | Install → tour → course folder → environment check → save/reopen |

## Exit criteria
The student can:
1. Open Thonny from the Start menu.
2. Run `EnvironmentCheck.py` and see every line say `OK` and the Turtle drawing appear.
3. Save a file in the course folder, close Thonny, reopen it and find the file again.
4. Say in one sentence the difference between Python and Thonny.
