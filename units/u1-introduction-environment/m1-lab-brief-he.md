## 1. פתיחת הקובץ

פתחו את הקובץ `G7_U1_FirstProgram_Starter.py`. אל תריצו עדיין.

## 2. קריאה, חיזוי, הרצה ובדיקה

קראו את כל הקוד, כולל הגדרת הפונקציה. לפני ההרצה הראשונה, כתבו מה לדעתכם יופיע. רק אחר כך הריצו והשוו לתחזית.

## 3. שינוי

שנו את שלוש שורות `print` כך שיופיעו: השם שלכם, משהו שאתם אוהבים, ומשפט קצר לבחירתכם. בכל הדוגמאות היום השתמשו במרכאות כפולות.

## 4. אתגר סדר

החליפו את הסדר של שתי שורות. לפני ההרצה, חזו את סדר הפלט החדש.

## 5. תיעוד

הוסיפו בתחילת הקובץ את ההערה הזו, ועוד הערה אחת שמסבירה חלק מהקוד:

```python
# My first Python program
```

## 6. שלד פונקציה

החליפו את הטקסט `FIRST LINE` ואת הטקסט `SECOND LINE` בשני טקסטים אישיים משלכם. לאחר מכן מחקו את שלוש שורות הפלט המקוריות והוסיפו בסוף הקובץ קריאה לפונקציה. הריצו ובדקו שהפונקציה מדפיסה את שתי השורות שבחרתם.

```python
def introduce_me():
    print("FIRST LINE")
    print("SECOND LINE")
```

> [!TIP]
> כל השורות ששייכות לפונקציה מוזחות פנימה ומיושרות באותה צורה.

## 7. אתגר חיזוי מסכם

> [!IMPORTANT]
> אל תריצו עדיין.

סדרו את הקובץ כך שייראה כמו הדוגמה. החליפו את הטקסט האישי בשלכם והשאירו גם הערה שמסבירה חלק מהקוד.

```python
# My first Python program

print("Start")

# This function prints two facts about me
def introduce_me():
    print("My name is ...")
    print("I like ...")

print("Ready")
introduce_me()
print("End")
```

**לפני ההרצה:** כתבו את הפלט המדויק, שורה אחר שורה.

<div dir="rtl">

| שורה | התחזית שלי |
|:---:|---|
| 1 | &nbsp; |
| 2 | &nbsp; |
| 3 | &nbsp; |
| 4 | &nbsp; |
| 5 | &nbsp; |

</div>

**אחרי ההרצה:** האם התחזית התאימה? אם לא, סמנו את השורה הראשונה שבה התחזית שלכם שונה מהפלט.

אחרי ההרצה, היו מוכנים להסביר בעל פה מה גרם לפונקציה לבצע את ההוראות שבתוכה.
