קוראים ← חוזים ← מריצים ← בודקים ← משנים ← מתעדים ← שומרים

IMPORTANT

לפני כל הרצה: כותבים במחברת מה לדעתכם יודפס. רק אחר כך מריצים ובודקים.

NOTE

אלגוריתם הוא רצף פעולות שמוביל לפתרון של בעיה מסוימת. הספירה לאחור היא אלגוריתם בארבעה צעדים. קודם כותבים את הצעדים במילים, ואחר כך בקוד.

NOTE

Tool Note – Thonny

  • מריצים עם F5. הפלט מופיע בחלון Shell.
  • אחרי def ...: ו-Enter, השורה הבאה מוזחת לבד. לוחצים Backspace כדי לצאת מהפונקציה.

1. משנים את השיגור

  1. קובץ חדש (File › New). מקלידים את הספירה לאחור:
print("3")
print("2")
print("1")
print("Liftoff!")
  1. מריצים עם F5.
  2. משנים: הספירה מתחילה מ-5.
  3. מחליפים את Liftoff! בהודעה משלכם, באנגלית.
  4. חוזים ואז מנסים: מה יקרה אם נעביר את ההודעה לשורה הראשונה?
  5. שומרים: File › Save As בשם rocket.py.

2. ארבע השגיאות שפגשנו

מה כתבנו מה Python אומרת איך מתקנים
print(cat) NameError: name 'cat' is not defined שמים מרכאות סביב הטקסט
print("Hello) SyntaxError: unterminated string literal סוגרים את המרכאות
print("Hello" SyntaxError: '(' was never closed סוגרים את הסוגריים
Print("Hello") NameError: name 'Print' is not defined כותבים print באותיות קטנות

TIP

שורה שמתחילה ב-# היא הערה: הסבר לבני אדם, ו-Python מדלגת עליה. # בתחילת שורה "מכבה" אותה בלי למחוק.

3. מפעילים את הפונקציה (פעולה) בעצמכם

  1. קובץ חדש. מקלידים רק את ההגדרה של cheer, בלי זימון:
def cheer():
    print("Go team!")
    print("Go go go!")
  1. מריצים. מה הופיע בחלון Shell?
  2. לוחצים Backspace כדי לצאת מההזחה, כותבים cheer() ומריצים.
  3. חוזים: אם נזמן שלוש פעמים, כמה שורות יופיעו? מריצים ובודקים.

4. בפנים או בחוץ?

def hello():
    print("Hello!")
  1. מקלידים את הקוד.
  2. מוסיפים בתוך הפונקציה, מתחת ל-print("Hello!"), את השורה print("Bye!") עם אותה הזחה. מוסיפים בסוף הקובץ, בלי הזחה, את הזימון hello(). מריצים.
  3. מבטלים את ההזחה של שורת ה-Bye, כך שהיא תהיה מחוץ לפונקציה. חוזים: מה ישתנה בפלט? רק אחרי זה מריצים.
  4. מעבירים את הזימון hello() לשורה שמעל ההגדרה def. חוזים: מה יקרה? מריצים. (שגיאת NameError: אי אפשר לזמן פעולה לפני שהגדרנו אותה.)

5. מורידים שורה ומכניסים טאב

בתוך מחרוזת, \n פירושו "רד שורה" ו-\t פירושו "טאב" (קפיצה למרווח הבא):

print("python\nlanguage")
print("so\tcool")
  1. חוזים מה יודפס, מריצים ובודקים.
  2. כתבו תוכנית שמדפיסה את השם שלכם בשתי שורות, בעזרת \n.
  3. כתבו תוכנית שמדפיסה שם פרטי ושם משפחה עם טאב ביניהם, בעזרת \t.

6. אתגר השיגור: עולים בשלבים

  1. פותחים את rocket.py מתחילת השיעור (File › Open), ושומרים בשם חדש: File › Save As ← G7_U1_Rocket_<Name>.py
  2. מוסיפים מעל שורות הספירה את השורה def launch():, ומזיחים פנימה את כל שורות הספירה ואת שורת ה-Liftoff. מריצים. מה הודפס?
  3. מוסיפים בסוף הקובץ, בלי הזחה, את הזימון launch(). מריצים.
  4. מוסיפים זימון שני launch(). חוזים: כמה פעמים תודפס הספירה? מריצים ובודקים.
  5. (שיעורי בית) מוסיפים בתוך הפונקציה, לפני המספר הראשון, את השורה print("Ignition!"). מריצים.
  6. (שיעורי בית) מבטלים את ההזחה של שורת ה-Liftoff. חוזים: מתי היא תופיע עכשיו? מריצים. מחזירים את ההזחה, "מכבים" זימון אחד עם #, מוסיפים בראש הקובץ הערה שמסבירה מה התוכנית עושה, ושומרים.

אין לכם את rocket.py? בקשו מהמורה את הקובץ Rocket_Starter.py.

7. משימת יציאה: תוכנית שמציגה אתכם

7 דקות · לבד

קודם, במחברת: כתבו במילים את הצעדים של התוכנית (זה האלגוריתם). רק אחר כך בקוד.

כתבו קובץ חדש עם פונקציה introduce_me() שמדפיסה את השם שלכם ומשהו שאתם אוהבים. הוסיפו print לפני הזימון ואחריו, למשל:

print("Start")

def introduce_me():
    print("My name is Dana")
    print("I like basketball")

print("Ready")
introduce_me()
print("End")
