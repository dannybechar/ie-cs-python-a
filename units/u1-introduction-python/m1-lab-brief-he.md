## 2. ארבע השגיאות שפגשנו

<div dir="rtl">

| מה כתבנו | מה Python אומרת | איך מתקנים |
|---|---|---|
| `print(cat)` | `NameError: name 'cat' is not defined` | שמים מרכאות סביב הטקסט |
| `print("Hello)` | `SyntaxError: unterminated string literal` | סוגרים את המרכאות |
| `print("Hello"` | `SyntaxError: '(' was never closed` | סוגרים את הסוגריים |
| `Print("Hello")` | `NameError: name 'Print' is not defined` | כותבים print באותיות קטנות |

</div>

> [!TIP]
> שורה שמתחילה ב-`#` היא הערה: הסבר לבני אדם, ו-Python מדלגת עליה. `#` בתחילת שורה "מכבה" אותה בלי למחוק.

## 4. בפנים או בחוץ?

```python
def hello():
    print("Hello!")
```

<div dir="rtl">

1. מקלידים את הקוד.
2. מוסיפים בתוך הפונקציה, מתחת ל-`print("Hello!")`, את השורה `print("Bye!")` עם אותה הזחה. מוסיפים בסוף הקובץ, בלי הזחה, את הזימון `hello()`. מריצים.
3. מבטלים את ההזחה של שורת ה-Bye, כך שהיא תהיה מחוץ לפונקציה. חוזים: מה ישתנה בפלט? רק אחרי זה מריצים.

</div>
