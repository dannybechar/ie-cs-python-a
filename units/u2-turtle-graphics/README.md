## Unit 2 extra practice — 10 turtle exercises

Ten short exercises (the solutions are 17–20 lines of code each, no functions, loops or variables) for after the three meetings or as homework. Each file starts with a comment block that says what the exercise draws and what it practices. Difficulty is about "a rectangle in different colors and pen thicknesses", widened step by step: filled shapes, `dot`, `bgcolor`, `circle`, `write`.

**Dependency:** nine of the ten (all except 02) use `goto`, which the three taught meetings do not teach. Assign the extras only **after the addendum session** (coordinates block). An eleventh exercise, `11_QuadrantSquares.py` (four squares in the four quadrants, with solution), was added from the ministry's meeting 14 tasks 4-6.

New commands in the extras (not taught in 2.1-2.3) and where the ministry teaches them:

| Command | Meaning | Used in | Taught in |
|---|---|---|---|
| `goto(x, y)` | move to a point | 01, 03-10, 11 | addendum (ministry meeting 14) |
| `fillcolor`, `begin_fill`, `end_fill` | fill a closed shape | 03, 07 | addendum (meeting 14) |
| `bgcolor("...")` | window background | 07, 09, 10 | by the extra's header (meeting 14) |
| `dot(size, color)` | filled circle at the turtle | 04, 09 | by the extra's header (meeting 20) |
| `circle(radius)` | circle | 08 | by the extra's header (meeting 19) |
| `write(text, ...)` | text in the window | 10 | by the extra's header (meeting 20); Unit 6.4 uses it again |

The files: 01 ThickRedRectangle · 02 FourColorFrame · 03 FilledBlueRectangle · 04 TrafficLight · 05 HouseWithRedRoof · 06 ThreeColorRibbons · 07 GoldenStarInNightSky · 08 ConcentricColorRings · 09 SnowmanFromDots · 10 WelcomeSign · 11 QuadrantSquares.

## Unit 2 test

A 45-minute multiple-choice test for grades 7 and 8 covering all three meetings (25 questions, 4 points each). It checks that students listened in class and did the lab work: honest questions only, no tricks. Two parallel forms with different questions, each with a teacher key. The key lists difficulty (7 easy / 12 medium / 6 hard), topic and a short explanation per question. Expected class average is about 70, with very few students above 90; these are estimates, so adjust after the first class (see the key).

Built from the question data in [`tools/unit-test-builder/`](../../tools/unit-test-builder/README.md); reviewed by ChatGPT, see [`docs/reviews/unit2-test/`](../../docs/reviews/unit2-test/REVIEW-FOLLOWUP.md).

## Unit 2 written test

A 60-minute paper test (Form A, sat by Grade 8) on the five basic commands: `forward`, `left`, `right`, `penup`, `pendown`. Six questions worth 17/17/17/17/16/16 = 100 points: two multiple choice, two code analysis, two write-the-code. Every lettered sub-question brings its own code or start state, so a mistake in one does not cost the next. The instructions page has hints and a worked example of drawing on a grid. Four analysis items (3א, 3ב, 3ג, 4ב) ask students to draw the code's result on a grid that starts with a turtle arrow, and the drawing is graded. The test is scanned in black and white, so it uses no color. Writing and analysis items have a partial-credit rubric in the key, which also shows the solved grids. Estimated time is about 62 minutes for an average student; it is an estimate, not measured, and a pilot with three students is still open. First sitting (Grade 8, 29 Oct 2026, 36 students): mean 94.6, median 95.5, range 74–100; two rubric lines in 4ב and 4ג did not match the question text, so they were credited to everyone and the questions were reworded afterwards, see [`tools/unit-test-builder/README.md`](../../tools/unit-test-builder/README.md). Reviewed by ChatGPT, see [`docs/reviews/unit2-written-test/`](../../docs/reviews/unit2-written-test/REVIEW-FOLLOWUP.md).

Form B (Grade 7, `u2-turtle-test-b-{students,key}-he`): the same structure, marks (17/17/17/17/16/16) and about 62 minutes, with new items. After the Grade 8 sitting two things changed: all four grids are the same size (10 x 7 squares, one square = 50 steps) and have no start arrow, so the student marks a start square and the key judges the shape, not the position; and every rubric line is asked for in the question text. The instructions page spells out the drawing steps and has a worked example with the same grid. Verified with `tools/unit-test-builder/verify_turtle_test_b.py`; not ChatGPT-reviewed, and the time estimate is unmeasured. First sitting (Grade 7, 6 Nov 2026, 38 students): mean 90, median 92, range 65–100, 5 students at 100; the hardest item was 2ד (68% average, 12 of 38 scored zero), see [`tools/unit-test-builder/README.md`](../../tools/unit-test-builder/README.md).

Built from [`tools/unit-test-builder/`](../../tools/unit-test-builder/README.md) (`questions-turtle-a.js`, `build-written.js`); answers checked with `verify_turtle_test.py`.
