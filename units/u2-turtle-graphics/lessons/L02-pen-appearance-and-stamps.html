NOTE

Tool Note – Thonny

  • סוגרים את חלון הציור לפני שמריצים שוב.
  • מה ש-print מדפיס מופיע בחלון Shell, לא בחלון הציור.
  • אחרי def ...: ו-Enter, השורה הבאה מוזחת לבד. לוחצים Backspace כדי לצאת מהפונקציה.

הפקודות החדשות

במבחן מחלקים אותן לקבוצות: פעולות עט (penup, pendown, pensize, pencolor) ופעולות עיצוב (shape, stamp, hideturtle, showturtle).

פקודה מה היא עושה
turtle.penup() מרימה את העט: הצב זז בלי לצייר
turtle.pendown() מורידה את העט: הצב מצייר שוב
turtle.pencolor("red") משנה את צבע העט
turtle.pensize(5) משנה את עובי העט
turtle.shape("circle") משנה את צורת הצב
turtle.stamp() משאירה חותמת בצורת הצב
turtle.hideturtle() מסתירה את הצב
turtle.showturtle() מציגה את הצב שוב

TIP

כל הגדרה נשארת עד שמשנים אותה: עט למעלה או למטה, צבע ועובי. צבעים וצורות כותבים עם מרכאות, באנגלית: "red", "blue", "green", "orange", "circle", "arrow", "turtle".

ככה כל הרצה מתחילה מחדש, וההגדרות של משימה אחת לא "נדבקות" למשימה הבאה.

1. חימום: מה יופיע?

פתחו את TurtlePenStamp_Starter.py. אל תריצו עדיין. קראו את הפונקציה warm_up(), נחשו מה עושה penup, שרטטו, ורק אז הריצו.

2. משימה A: כביש מקווקו

כתבו פונקציה חדשה בשם dashed_road(), שמציירת קו ישר מקווקו עם 3 מקפים. כל מקף באורך 30, והרווח בין מקפים הוא 15.

הפכו את warm_up() להערה, וזמנו את dashed_road().

אתגר: מחקו את ה-pendown() השני. חזו כמה מקפים יישארו, ורק אז הריצו.

3. משימה B: ריבוע צבעוני

לפני שמתחילים: הוסיפו בסוף dashed_road() את turtle.hideturtle() והריצו. לאן נעלם הצב? עכשיו הוסיפו אחריה turtle.showturtle() והריצו שוב.

כתבו פונקציה בשם color_square(): ריבוע 100 על 100 עם עט בעובי 5, כשכל צלע בצבע אחר. בסוף הצב מסתכל לכיוון ההתחלה ומוסתר.

שאלה: האם pencolor צריך לבוא לפני ה-forward של הצלע או אחריו?

4. משימה C: אבני קפיצה

כתבו פונקציה בשם stepping_stones(): שלוש אבנים עגולות בשורה, במרחק 50 זו מזו, בלי קו ביניהן. בסוף רואים רק את האבנים. השתמשו ב-8 פקודות לכל היותר.

רמז: shape("circle"), penup() ו-stamp().

5. משימה D: לעדכן או לאחזר?

כתבו פונקציה בשם read_the_pen() עם השורות האלה, והפכו את כל שאר הזימונים להערות. לפני ההרצה, כתבו מה יופיע בחלון Shell:

def read_the_pen():
    print(turtle.pensize())
    turtle.pensize(8)
    print(turtle.pensize())
    print(turtle.pencolor())
  • עם ערך בסוגריים: הפקודה מעדכנת את ההגדרה. משנים.
  • עם סוגריים ריקים: הפקודה מאחזרת את ההגדרה הנוכחית. שואלים מה הערך עכשיו.

שאלה: במשימה B השתמשנו בכתום. למה עכשיו הצבע הוא black?
