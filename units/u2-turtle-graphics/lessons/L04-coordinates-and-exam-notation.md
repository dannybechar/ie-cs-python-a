## 1. הצב יודע איפה הוא עומד

חלון הציור הוא מערכת צירים. כל נקודה נקבעת בשני מספרים **(x, y)**: x הוא ימינה ושמאלה, y הוא למעלה ולמטה.

- הצב מתחיל ב-**(0, 0)**, באמצע, ומסתכל ימינה.
- מצב ההתחלה: צורה חץ (עד שמחליפים ב-`shape`), צבע שחור, מיקום (0, 0), כיוון ימינה.
- ארבעה רביעים: **1** (x חיובי, y חיובי) · **2** (x שלילי, y חיובי) · **3** (שניהם שליליים) · **4** (x חיובי, y שלילי). נקודה על ציר לא שייכת לאף רביע.

**חימום בלי מחשב:** מסמנים על הצירים את (2, 4), (‏−3, 5), (4, ‏−2), (0, 0), וכותבים באיזה רביע כל נקודה.

## 2. פעולות מיקום

<div dir="rtl">

| פקודה | מה היא עושה |
|---|---|
| `turtle.goto(100, 50)` | הצב עובר לנקודה (100, 50). **אם העט למטה, נשאר קו** |
| `turtle.setx(100)` | משנה רק את x. y נשאר כמו שהיה |
| `turtle.sety(50)` | משנה רק את y. x נשאר כמו שהיה |
| `turtle.position()` | **מאחזרת** את המיקום: `print(turtle.position())` |
| `turtle.penup()` ‏+ `goto` ‏+ `turtle.pendown()` | קפיצה בלי לצייר |

</div>

> [!TIP]
> `goto` **לא מסובב** את הצב. הוא רק מזיז אותו. בין x ל-y שמים פסיק: `goto(100, 50)`.
> `penup()` ו-`pendown()` לא מקבלות מספרים בסוגריים.

**משימות** (קובץ `Coordinates_Starter.py`, פונקציה לכל משימה):

1. חימום: מה יצויר? כותבים את ארבע הנקודות ואז מריצים.
2. משימה A: קופצים ל-(‏−150, 80) בלי קו, ומציירים קו ל-(150, 80).
3. משימה B: ריבוע 100 × 100 מ-(0, 0) רק עם `setx` ו-`sety`.
4. משימה C: ריבוע בצלע 80 ברביע 2, פינה ב-(‏−120, 40).
5. משימה D (הרחבה): ארבעה ריבועים, אחד בכל רביע.

## 3. שמות קצרים וצעד אחורה

<div dir="rtl">

| שם ארוך | שם קצר | |
|---|---|---|
| `forward` | `fd` | קדימה |
| `backward` | `back`, `bk` | אחורה, **בלי להסתובב** |
| `left` | `lt` | פנייה שמאלה |
| `right` | `rt` | פנייה ימינה |
| `penup` | `pu`, `up` | העט למעלה |
| `pendown` | `pd`, `down` | העט למטה |

</div>

אנחנו כותבים שמות ארוכים, כי הם מסבירים את עצמם. במבחן אפשר לראות שמות קצרים, ולכן צריך **לקרוא** אותם.

## 4. `color` ו-`pencolor`, מילוי וגודל הצב

- `turtle.pencolor("red")` – רק הקו.
- `turtle.color("red")` – הקו **והצב** (וגם החותמות).
- צבע אפשר לכתוב גם בקוד: `"#1AA260"`.
- מילוי: `turtle.fillcolor("yellow")`, ואז `turtle.begin_fill()`, מציירים צורה, `turtle.end_fill()`.
  **שאלה:** מה קורה אם הצורה לא סגורה? מנבאים ואז בודקים.
- `turtle.turtlesize(2)` – מגדיל את הצב.

**מי מסובב כאן?** (אופציונלי) מציירים שלוש זוויות, כל אחת בפונקציה משלה: זווית ישרה (פנייה 90), זווית חדה של 35° (פנייה **145**), זווית קהה של 135° (פנייה **45**). הצב מסתובב בזווית החיצונית.

## 5. אותה תוכנית, בשתי צורות כתיבה

בכיתה אנחנו כותבים `turtle.forward(100)`. במבחן נותנים **שם** לחלון ושם לצב, והפקודות נכתבות אחרי שם הצב. זה אותו צב ואותן פקודות, רק הכתיבה שונה.

<div dir="ltr">

| כתיבה בכיתה | כתיבה במבחן |
|---|---|
| `import turtle` | `import turtle` |
| `turtle.Screen()` | `wn = turtle.Screen()` |
| | `pen = turtle.Turtle()` |
| `turtle.forward(100)` | `pen.forward(100)` |
| `turtle.left(90)` | `pen.left(90)` או `pen.lt(90)` |
| `turtle.done()` | `wn.mainloop()` |

</div>

`wn` ו-`pen` הם **שמות** (אפשר גם `player`). נלמד שמות ומשתנים ביחידה 3; היום זו רק כתיבה.
במבחן קוראים לכל פקודה כזו **פעולה** של הצב.

**תרגיל** (קובץ `ExamDialect_Starter.py`):

1. מריצים את חלק 1 (סגנון הכיתה) ורואים מה מצויר.
2. חלק 2: כותבים את אותה תוכנית בכתיבה של המבחן. הציור צריך להיות זהה.
3. חלק 3: קוראים קוד בכתיבה של המבחן, אומרים מה הוא מצייר, וכותבים אותו מחדש בכתיבה של הכיתה.

**שאלות קריאה (בלי מחשב):**
