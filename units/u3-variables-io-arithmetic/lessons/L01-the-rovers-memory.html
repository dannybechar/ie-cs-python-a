יחידה 3.1 – משתנים, קלט/פלט וחישובים

כיתה ז׳ · Python A · הזיכרון של הרובר: משתנים, טיפוסים וקלט

קוראים ← חוזים (טבלת מעקב) ← מריצים ← בודקים ← מתקנים

IMPORTANT

משתנה הוא קופסה עם שם, שמחזיקה ערך אחד. הסימן = אומר "שים בתוך": fuel = 50 שם את 50 בקופסה בשם fuel.

ארבעה טיפוסים

טיפוס דוגמה במילים
int 12, -3 מספר שלם
float 3.5, 7.0 מספר עשרוני (ממשי)
str "Dana", "7" מחרוזת: כל מה שבתוך מרכאות
bool True, False בוליאני: אמת או שקר

TIP

הפקודה input() תמיד נותנת טקסט, גם כשמקלידים מספר. כדי לקבל מספר: int(input(...)) למספר שלם, float(input(...)) למספר עשרוני.

שמות משתנים

שם חוקי? למה
fuel, rover_name כן אותיות באנגלית, _ במקום רווח
2fuel לא אי אפשר להתחיל בספרה
my fuel לא אסור רווח
my-fuel לא אסור תו מיוחד (- הוא מינוס)
for לא מילה שמורה: לפייתון יש בה כבר שימוש
  • חוק: אם שוברים אותו, התוכנית לא רצה (כל ה"לא" שבטבלה).
  • מוסכמה: התוכנית רצה, אבל כך נהוג: אותיות באנגלית ושם עם משמעות (fuel, לא x).

פלט ידידותי ופלט ביניים

  • פלט ידידותי: תווית שמסבירה לקורא מה הערך: print("Name:", name).
  • פלט ביניים: הדפסת ערך באמצע התוכנית כדי לבדוק שהוא נכון.

1. חימום: יומן הרובר

פתחו את Variables_Starter.py. אל תריצו עדיין!

planet = "Mars"
distance = 225
speed = 3.5
landed = False

print("Planet:", planet)
print("Distance:", distance)
print("Speed:", speed)
print("Landed:", landed)

landed = True
print("Landed:", landed)

מלאו את טבלת המעקב, ורק אחר כך הריצו ובדקו:

שורה planet distance speed landed פלט
1–4          
print ×4          
landed = True          
print          

מה הטיפוס של כל משתנה? planet: __ · distance: _ · speed: · landed: ___

חימום ב׳: השמה מרובה

אפשר לתת ערכים לכמה משתנים בשורה אחת. הערך הראשון נכנס לשם הראשון, וכן הלאה:

fuel, speed = 80, 3.5
print(fuel, speed)

הוסיפו לטבלת המעקב שורה אחת: אילו שתי עמודות השתנו בה?

חימום ג׳: המרה של משתנה שכבר קיים

x = 7
y = float(x)
print(y, type(y))
text = str(5)
print(text, type(text))

חזו מה יודפס, ואז הריצו. str(...) הופכת ערך למחרוזת.

מה המטרה של הקוד הזה? (אל תריצו קודם.)

number_int = int(input("Number: "))
number_float = float(number_int)
print(number_float)
