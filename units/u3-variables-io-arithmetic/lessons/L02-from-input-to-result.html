דף עזר

פעולה משמעות דוגמה
+ חיבור 12 + 5 ← 17
- חיסור 12 - 5 ← 7
* כפל 12 * 5 ← 60
/ חילוק 12 / 5 ← 2.4
** חזקה 5 ** 2 ← 25
// מנה שלמה / חלוקת שלמים (כמה קבוצות שלמות) 17 // 5 ← 3
% שארית חלוקה / מודולו 17 % 5 ← 2

TIP

סדר הפעולות: סוגריים, אחר כך **, אחר כך * / // %, ובסוף + -.

IMPORTANT

היום, בכל הדוגמאות של // ו-%, משתמשים במספרים שלמים חיוביים, ומחלקים במספר גדול מ-0.

6ב. החלפה בעזרת temp ועדכון עצמי
