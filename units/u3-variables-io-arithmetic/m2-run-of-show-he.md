# שיעור 3.2 · סדר ההוראה ליום ראשון 15 בנובמבר (כיתות ז׳ וח׳)

90 דקות: **45 דקות שיעור** (הדרכה ותרגול קצר) ו-**45 דקות מעבדה**. אותו סדר בשתי הכיתות. התוספת למצגת היא **8 שקופיות בלבד**, כדי להשאיר זמן למעבדה.

**חומרים:**
1. המצגת הקיימת `m2-slides-he.pdf` (22 שקופיות, NotebookLM), מסומנת **"ראשית"** בטבלה.
2. חבילת התוספות `m2-addon-slides-he.pdf` (**8 שקופיות**, רקע לבן), מסומנת **"תוספת"**. היא מכסה רק את מה שאין במצגת הראשית: חזרה מ-3.1, `**`, החלפה ועדכון.
3. דף המעבדה `m2-lab-sheet-he.pdf` (הדפסה דו-צדדית, מפתח בקובץ `u3-lab-sheets-key-he.pdf`).
4. קוד להדגמה חיה ב-Thonny: `solutions/Recap_Demo.py` (חזרה), `exercises/Arithmetic_Starter.py` ו-`exercises/Packing_Starter.py` (מעבדה).
5. תסריט החזרה המלא: `m2-recap-he.md`.

> בכל שקופית שאלה: קודם מנחשים, ורק אז מריצים. **שקופיות ראשיות 2–3 (ציון) ו-12–13 (צב) מדלגים עליהן**: הראשונות מוחלפות בחזרה, והשניות בוטלו מהתוכנית.
