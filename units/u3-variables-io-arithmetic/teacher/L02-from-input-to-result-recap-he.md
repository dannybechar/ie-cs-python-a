## 1:00–2:00 · השמה מרובה

```python
a, b = 12, 5
print(a, b)
```

תשובה: `12 5`. זו **שורה אחת שעושה שתי השמות**, לפי הסדר: הערך הראשון לשם הראשון, השני לשני. שקול ל-`a = 12` ול-`b = 5` בשתי שורות. בטבלת מעקב: שורה אחת, ושתי העמודות משתנות יחד.

## 2:00–3:00 · המרה של משתנה ששמור, ו-`str()`

בשבוע שעבר המרנו **ברגע הקלט**: `int(input())`. אפשר להמיר גם משתנה **שכבר שמור**.

```python
x = 7
y = float(x)
print(y, type(y))     # 7.0 <class 'float'>
t = str(5)
print(t, type(t))     # 5 <class 'str'>
```

`x` נשאר 7; `y` קיבל עותק עשרוני. `str()` הופכת למחרוזת: נראה כמו 5 אבל זה טקסט (כמו מה ש-`input` מחזירה).

## 3:00–4:00 · "מה מטרת הקוד?" (כך שואלים בבחינה)

```python
number_int = int(input())
number_float = float(number_int)
print(number_float)
```

מקלידים 34, יודפס `34.0`. תשובה מצופה: **"הקוד קולט מספר שלם ומדפיס אותו כמספר עשרוני."**

## 4:00–5:00 · תשובות (שקופית 2) והערה בעל פה: שמות

אחרי השקופית אומרים בקול, בלי שקופית (30 שניות, אפשר להריץ בבלוק 4):

- `my-fuel = 5` ← שגיאה: מקף הוא תו מיוחד (נקרא כחיסור). `for = 5` ← שגיאה: `for` היא **מילה שמורה**.
- `Fuel = 5` רץ בלי שגיאה: זו **מוסכמה** (מקובל באותיות קטנות), לא **חוק בל יעבור**.

(הניסוח "חוק בל יעבור" מול "מוסכמה" הוא של משרד החינוך.)
