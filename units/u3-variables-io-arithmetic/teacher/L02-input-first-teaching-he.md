## קוד להדגמה

```python
name = input("What is your name? ")
print("Hello,", name)

age = input("Age: ")
print(age, type(age))          # מקלידים 12 ← 12 <class 'str'>

age = int(input("Age: "))
print(age, type(age))          # <class 'int'>

height = float(input("Height: "))   # מקלידים 1.52
print(height, type(height))    # <class 'float'>
```

"מה מטרת הקוד?" (מקלידים 34, יודפס `34.0`):

```python
number_int = int(input())
number_float = float(number_int)
print(number_float)
```

תשובה מצופה: **"הקוד קולט מספר שלם ומדפיס אותו כמספר עשרוני."**

## ארבעה דברים לזכור (בעל פה, בסוף)

1. `input()` עוצרת ומחכה; מה שהמשתמש מקליד נשמר במשתנה.
2. `input()` **תמיד** מחזירה טקסט.
3. מספר שלם: `int(input())`. עשרוני: `float(input())`.
4. טקסט שלא מתאים לטיפוס ← `ValueError`.

## אם מתעכבים

מקצרים את `ValueError` (דקות 7:30–9:00) לדקה אחת. לא מוותרים על: "גם מספר מגיע כטקסט" ועל `int(input())`.
