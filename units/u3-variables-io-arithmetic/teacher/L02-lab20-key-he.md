# מפתח · מעבדה 20 דקות (לפני הבוחן Q1)

דף התלמיד: [`../lessons/L02-from-input-to-result/lab20-sheet-he.html`](../lessons/L02-from-input-to-result/lab20-sheet-he.html) (A4, שחור-לבן, אותיות גדולות; מדפיסים דף אחד).
מבנה לפי כללי הדפים: שני סוגי שאלות בלבד (הריצו וענו; כתבו קוד), קוד בתיבה השמאלית, תשובה בתיבה הימנית, בלי שורות.

| # | סוג | דקות | תשובה |
|---|---|---|---|
| 1 | הריצו | 4 | הקלט 17 ו-5. מודפס: `3`, `2`, `3.4`. `//` חלק שלם (3 חבילות מלאות), `%` שארית (2 נשארו), `/` חילוק רגיל, תמיד עשרוני |
| 2 | הריצו | 4 | הקלט 23. מודפס: `2 3` ואז `5`. עבור 47: `4 7` ואז `11`. `// 10` נותן ספרת העשרות, `% 10` ספרת האחדות |
| 3 | כתבו קוד | 8 | ראו הקוד למטה. בדיקות: 135 ← `2 15`; 59 ← `0 59` |
| ★ | כתבו קוד | 4 | ראו למטה. 90 ו-85 ← `87.5`; הממוצע יכול להיות עשרוני, לכן `/` |

```python
# 3
minutes = int(input("Minutes: "))
hours = minutes // 60
left = minutes % 60
print(hours, left)

# ★
g1 = int(input("Grade 1: "))
g2 = int(input("Grade 2: "))
avg = (g1 + g2) / 2
print(avg)
```

## עמוד 2 · תרגול נוסף (למי שמסיים או לבית; `%` מתורגל אבל לא נשאל בבוחן)

| # | סוג | תשובה |
|---|---|---|
| א | הריצו | `17`, `24`, `13`. סוגריים משנים את סדר הפעולות; כפל לפני חיבור, וחיסור משמאל לימין |
| ב | הריצו | `2.5`, `2`, `2`, `2.0`. סוג התוצאה של `/` תמיד `float`, גם כשהחילוק מדויק |
| ג | הריצו | אחרי השורות: `5`, `8`, `16`, `15`; מודפס `15` |
| ד | כתבו קוד | `price = 12`, `total = price * 3`, `change = 50 - total`; מודפס `36` ו-`14` |
| ה | כתבו קוד | `38 // 5` ← `7`, `38 % 5` ← `3` |
| ו | כתבו קוד | `f = 20 * 9 / 5 + 32` ← `68.0` |

**טעויות נפוצות:** שוכחים `int(...)` ואז `//` נכשל עם `TypeError` (טקסט); `(g1 + g2) / 2` בלי סוגריים; מדפיסים `hours` ו-`left` בלי להמיר.
**קישורים:** נושאי השאלות 1–2 הם `//` ו-`%`, בדיוק מה שבבוחן Q1.
