# מפתח תשובות (למורה) · בוחן קצר יחידה 3 – 5 שאלות, 29 בנובמבר

**קובץ תלמיד:** [`../assessment/quiz-5q-nov29-he.html`](../assessment/quiz-5q-nov29-he.html) · **לא להפיץ.**

בוחן חלופי בן 5 שאלות (20 נק׳, 4 לכל שאלה), מכוון ברמת קושי גבוהה יותר מ-[`u3-quiz-students-he.pdf`](../assessment/u3-quiz-students-he.pdf) המאושר: כל שאלה כוללת ניסוח שדורש תשומת לב מיוחדת, או מספרים שלא נראו כלשונם בשקופיות. מתוכנן כך שתלמיד מתקשה יגיע ל-50%, ממוצע ל-75%, מצטיין ל-95%.

## שאלה 1 — טיפוסים (4 נק׳)
`'12'` → `str` (שני תווים בין מרכאות — **לא** `char`, גם אם זה "נראה" כמו מספר) · `5.0` → `float` · `"True"` → `str` (המילה True בתוך מרכאות היא טקסט, לא `bool`) · `False` → `bool`.
ניקוד: נקודה על כל ערך. שימו לב כפול: הבדלה בין `char` (תו בודד) ל-`str` (כמה תווים), והבדלה בין `bool` אמיתי לבין המילה "True" בתוך מרכאות.

## שאלה 2 — שמות משתנים (4 נק׳)
חוקיים: `_hidden` (מותר להתחיל בקו תחתון), `Total_Score` (אות גדולה מותרת תחבירית — מוסכמה, לא חוק, ראו `L02-from-input-to-result-recap-he.md`). פסולים: `2nd-try` (מתחיל בספרה, וגם מקף הוא אופרטור חיסור), `class` (מילה שמורה של Python).
ניקוד: נקודה על כל שם. שימו לב: `Total_Score` נראה "לא תקני" בגלל האות הגדולה, אבל Python מקבל אותו; `class` נראה כמו שם רגיל אך הוא מילה שמורה.

## שאלה 3 — סדר פעולות (4 נק׳)
`20 - 3 * 4 + 10 // 3` = `20 - 12 + 3` = `11`
`(20 - 3) * 4 + 10 // 3` = `17 * 4 + 3` = `71`
`100 // 9 % 4` = `11 % 4` = `3`
`100 % 9 // 2` = `1 // 2` = `0`
ניקוד: נקודה על כל שורה. דורש קדימות נכונה בין `*`/`//`/`%` לבין `+`/`-`, **וגם** חישוב משמאל לימין בין שני אופרטורים מאותה רמת קדימות (שורות 3–4) — קושי מעבר לבוחן המאושר.

## שאלה 4 — טבלת מעקב: סיבוב של שלושה משתנים (4 נק׳)
```python
a = 3; b = 7; c = 12
a = b   # a:7  b:7  c:12
b = c   # a:7  b:12 c:12
c = a   # a:7  b:12 c:7
print(a, b, c)   # 7 12 7
```
ניקוד: נקודה על כל אחת משלוש שורות הטבלה (כל הערכים באותה שורה נכונים יחד), ונקודה על הפלט הסופי `7 12 7`. הרחבה של הנקודה הרגישה בהחלפה (ממצגת הסקירה שקופית 4 ומשימה 2 במעבדה) לשלושה משתנים — השורה הקריטית היא `c = a`, שמשתמשת כבר ב-`a` **אחרי** שהשתנה.

## שאלה 5 — הזמנה בבית ספר (4 נק׳)
143 מחברות, 9 בקופסה, 27 ש״ח לקופסה, ועוד 3 ש״ח דמי טיפול **על כל קופסה**.
א. `143 // 9` = `15` — נקודה על הביטוי והערך יחד.
ב. `(143 // 9) * (27 + 3)` = `15 * 30` = `450` — נקודה על הביטוי (כולל שני זוגות הסוגריים) והערך יחד.
ג. (נקודה אחת) ההסבר המצופה: בלי הסוגריים סביב `27 + 3`, `*` קודמת ל-`+`, ולכן `143 // 9 * 27 + 3` מחשבת קודם `15 * 27 = 405` ורק אז מוסיפה `3` **פעם אחת בלבד** במקום להוסיף 3 ש״ח על כל אחת מ-15 הקופסאות — התוצאה השגויה היא `405 + 3 = 408` במקום `450`.

**הערת מורה:** זו אותה נקודת תשומת לב בסדר פעולות כמו משימה 5 במעבדה (דמי הביטוח), בניסוח שונה, כדי לבדוק אם התלמיד מכליל את הכלל ולא רק זוכר דוגמה ספציפית.
