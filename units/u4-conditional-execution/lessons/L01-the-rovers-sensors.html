יחידה 4.1 – ביצוע מותנה

כיתה ז׳ · Python A · החיישנים של הרובר: אמת או שקר?

קוראים ← חוזים ← מריצים ← בודקים ← מתקנים

IMPORTANT

השוואה היא שאלה שהתוכנית שואלת. התשובה היא תמיד True (אמת) או False (שקר).

דף עזר

סימן שאלה דוגמה (age = 13)
== שווה? age == 15 ← False
!= שונה? age != 10 ← True
> גדול? age > 13 ← False
< קטן? age < 20 ← True
>= לפחות? age >= 12 ← True
<= לכל היותר? age <= 12 ← False

TIP

הסימן = שם ערך בקופסה. הסימן == שואל "האם שווה?". המילה and אמת רק כששני הצדדים אמת. המילה or אמת כשלפחות צד אחד אמת. המילה not הופכת את התשובה: not True הוא False.

  • הסימנים == != > < >= <= נקראים אופרטורי יחס. המילים and, or, not נקראות קשרים לוגיים.
  • בבחינה קוראים לפונקציה פעולה: "כתבו פעולה" פירושו "כתבו פונקציה".
