IMPORTANT

התשובה לשאלה (True או False) קובעת אילו שורות ירוצו.

דף עזר

number = int(input("Number: "))
if number % 2 == 0:
    print("Even")
else:
    print("Odd")
print("Done")
  • אחרי התנאי — נקודתיים :
  • גוף ה-if וגוף ה-else — מוזחים (4 רווחים).
  • בכל הרצה רץ מסלול אחד בדיוק: if או else.
  • השורה print("Done") לא מוזחת, ולכן היא רצה תמיד.
  • ספרת העשרות של מספר דו-ספרתי: number // 10. ספרת האחדות: number % 10.
  • "אי-זוגי" אפשר לכתוב גם not (number % 2 == 0).
  • תנאי עם שני מסלולים נקרא תנאי פשוט. בבחינה קוראים לפונקציה פעולה.
