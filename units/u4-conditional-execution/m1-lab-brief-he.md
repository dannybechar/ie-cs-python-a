# החיישנים של הרובר: אמת או שקר?

כיתה ז׳ · יחידה 4 · מפגש 1 · Python A

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> השוואה היא שאלה שהתוכנית שואלת. התשובה היא תמיד `True` (אמת) או `False` (שקר).

## דף עזר

<div dir="rtl">

| סימן | שאלה | דוגמה (age = 13) |
|---|---|---|
| `==` | שווה? | `age == 15` ← `False` |
| `!=` | שונה? | `age != 10` ← `True` |
| `>` | גדול? | `age > 13` ← `False` |
| `<` | קטן? | `age < 20` ← `True` |
| `>=` | לפחות? | `age >= 12` ← `True` |
| `<=` | לכל היותר? | `age <= 12` ← `False` |

</div>

> [!TIP]
> הסימן `=` שם ערך בקופסה. הסימן `==` שואל "האם שווה?".
> המילה `and` אמת רק כששני הצדדים אמת. המילה `or` אמת כשלפחות צד אחד אמת.
