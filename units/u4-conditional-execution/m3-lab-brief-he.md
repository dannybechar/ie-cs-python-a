**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> שתי שאלות, החלטה אחת: מחברים אותן עם `and` או `or`, או שואלים את השנייה בתוך הראשונה.

## דף עזר

```python
# Nested
if age >= 12:
    if has_ticket == "yes":
        print("Enter")

# Compound
if age >= 12 and has_ticket == "yes":
    print("Enter")
```

<div dir="rtl">

- ה-`if` הפנימי נבדק רק כשהתנאי החיצוני `True`.
- כל רמת קינון מוסיפה 4 רווחים.
- כל צד של `or` צריך השוואה משלו.
- `else` שייך ל-`if` הקרוב ביותר באותה הזחה.

</div>

```python
if battery >= 70:
    print("Green")
elif battery >= 30:
    print("Yellow")
else:
    print("Red")
```

<div dir="rtl">

- **תנאי מתגלגל** (`if` / `elif` / `else`): התנאי הראשון שמתקיים מנצח, והשאר מדולגים. הסדר חשוב.
- ארבעה סוגי תנאים: **פשוט**, **מורכב**, **מקונן**, **מתגלגל**.
- בבחינה קוראים לפונקציה **פעולה**.

</div>
