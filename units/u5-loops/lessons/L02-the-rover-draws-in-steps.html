דף עזר

טווח ערכים
range(5) 0, 1, 2, 3, 4
range(2, 6) 2, 3, 4, 5
range(1, 10, 3) 1, 4, 7
range(5, 0, -1) 5, 4, 3, 2, 1
  • הערך stop אף פעם לא נכלל.
  • כדי לספור לאחור, הצעד שלילי.
  • במצולע משוכלל עם n צלעות פונים 360 / n בכל פעם.
  • התכונה (הפרמטר) end של print: print(number, end=" ") ממשיכה באותה שורה; end="," מוסיפה פסיק אחרי כל ערך. print() לבדה מסיימת את השורה.
  • שתי דרכים לקבל כפולות: for עם if number % 3 == 0, או range עם צעד.
  • בשפת משרד החינוך "פונקציה" נקראת גם פעולה.

1. הדפסה בשורה אחת

  1. הדפיסו את המספרים 1 עד 7 בשורה אחת, עם רווח בין המספרים.
  2. הדפיסו את 2, 4, 6, 8, 10 בשורה אחת, עם פסיק אחרי כל מספר.
  3. מה עושה print() אחרי הלולאה?

2. לולאה עם if או צעד?

  1. חזו מה ידפיס הקוד, והריצו:
for number in range(17):
    if number % 3 == 0:
        print(number, end=" ")
  1. כתבו לולאה אחרת עם range ועם צעד, שמדפיסה את אותם מספרים. האם הפלט זהה?
  2. בוּם 7: הדפיסו את המספרים 1 עד 50, ובמקום מספר שמתחלק ב-7, מסתיים ב-7, או שספרת העשרות שלו היא 7 — הדפיסו Boom. שימו לב: number / 10 == 7 לא עובד; השתמשו ב-number // 10 == 7.
