## דף עזר

<div dir="rtl">

| טווח | ערכים |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(2, 6)` | 2, 3, 4, 5 |
| `range(1, 10, 3)` | 1, 4, 7 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |

</div>

<div dir="rtl">

- הערך stop אף פעם לא נכלל.
- כדי לספור לאחור, הצעד שלילי.
- במצולע משוכלל עם n צלעות פונים `360 / n` בכל פעם.
- התכונה (הפרמטר) `end` של `print`: `print(number, end=" ")` ממשיכה באותה שורה; `end=","` מוסיפה פסיק אחרי כל ערך. `print()` לבדה מסיימת את השורה.
- שתי דרכים לקבל כפולות: `for` עם `if number % 3 == 0`, או `range` עם צעד.
- בשפת משרד החינוך "פונקציה" נקראת גם **פעולה**.

</div>

## 2. לולאה עם `if` או צעד?

<div dir="rtl">

1. חזו מה ידפיס הקוד, והריצו:

</div>

```python
for number in range(17):
    if number % 3 == 0:
        print(number, end=" ")
```

<div dir="rtl">

2. כתבו לולאה אחרת עם `range` ועם צעד, שמדפיסה את אותם מספרים. האם הפלט זהה?
3. בוּם 7: הדפיסו את המספרים 1 עד 50, ובמקום מספר שמתחלק ב-7, מסתיים ב-7, או שספרת העשרות שלו היא 7 — הדפיסו `Boom`. שימו לב: `number / 10 == 7` לא עובד; השתמשו ב-`number // 10 == 7`.

</div>
