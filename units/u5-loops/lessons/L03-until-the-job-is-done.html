IMPORTANT

הלולאה while חוזרת כל עוד התנאי True. משהו בתוך הלולאה חייב לקרב אותה לסיום.

דף עזר

count = 1
while count <= 5:
    print(count)
    count = count + 1
print("Finished")
  • ערך התחלה — לפני הלולאה.
  • תנאי — נבדק לפני כל סבב.
  • עדכון — בתוך הלולאה, מקרב לסיום.
  • מספר הסבבים ידוע מראש ← for. הסיום תלוי בתנאי ← while.
  • x += 3 זהה ל-x = x + 3.
  • הספרה האחרונה: number % 10. מוחקים אותה: number // 10.
  • בשפת משרד החינוך "פונקציה" נקראת גם פעולה, והתנאי נקרא "תנאי עצירה".
