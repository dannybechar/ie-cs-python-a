IMPORTANT

בכל סבב של הלולאה החיצונית, הלולאה הפנימית מבצעת את כל הסבבים שלה.

דף עזר

for row in range(3):
    for column in range(5):
        print("*", end="")
    print()
  • התכונה (הפרמטר) end="" ממשיכה באותה שורה.
  • הפקודה print() אחרי הלולאה הפנימית מסיימת שורה.
  • מספר ההרצות: סבבים חיצוניים × סבבים פנימיים.
  • תנאי מתגלגל (if / elif / else): בודקים לפי הסדר, הראשון שמתקיים מבוצע, והשאר מדולגים. בתוך for השרשרת רצה בכל סבב.
  • בכל סבב הערך ממשיך מהערך שהשאיר הסבב הקודם (מעקב).
  • בשפת משרד החינוך "פונקציה" נקראת גם פעולה.

1. משימה 1: דפוסי כוכבים

פתחו את Nested_Starter.py:

# Task 1: this should print 2 rows of 3 stars. Fix the indentation.
for row in range(2):
    for column in range(3):
        print("*", end="")
        print()
  1. תקנו את ההזחה כך שיודפסו שתי שורות של שלושה כוכבים.
  2. כתבו פונקציה בשם patterns() שמדפיסה מלבן של 4 שורות ו-6 סימני #.
  3. הוסיפו משולש: שורה 1 עם כוכב אחד, ועד שורה 5 עם חמישה כוכבים.

2. משימה 2: סופר פייתון

כתבו פונקציה בשם super_python() שקולטת את הציונים של 10 תלמידים. לכל ציון היא מדפיסה דרגה:

ציון דרגה
90 ומעלה Super
78 עד 89 Good
55 עד 77 Pass
מתחת ל-55 Fail

בסוף הדפיסו כמה תלמידים קיבלו Super וכמה Fail.

בדקו עם: 95, 80, 60, 40, 91, 78, 55, 54, 100, 20.

אתגר: חשבו את ממוצע הציונים של ה-Super (שימו לב למקרה שאין אף Super).

5. נקודת ביקורת ב׳ (על דף, בלי להריץ)

for row in range(3):
    for column in range(2):
        print("*", end="")
    print("|")
  1. מה ידפיס הקוד? כמה כוכבים?
  2. כמה סבבים יש ב-range(10, 0, -3), ובאילו ערכים?
  3. לולאות שקולות: איזו לולאת while מדפיסה אותו פלט כמו כל אחת מלולאות ה-for?
# for A
for item in range(2, 10, 2):
    print(item)
# for B
for item in range(1, 4):
    print(item)
# while 1
i = 1
while i <= 4:
    print(i)
    i += 1
# while 2
i = 2
while i < 10:
    print(i)
    i += 2
# while 3
i = 1
while i < 4:
    print(i)
    i += 1
  1. מה ידפיס הקוד, ומה מטרתו?
total = 0
for number in range(1, 10):
    if number % 2 == 1:
        total += number
print(total)
  1. השלימו כך שיודפס 6 4 2: for item in range(6, ___, ___): print(item, end=" ")
  2. הערך ממשיך מסבב לסבב: x = 3, ואז שלושה סבבים של x = x + x. מה ערך x אחרי כל סבב?
  3. סופית או אינסופית, ולמה? i = 1 ואז while i != 6: print(i); i += 2
