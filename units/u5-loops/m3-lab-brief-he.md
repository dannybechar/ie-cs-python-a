# יחידה 5.3 – ביצוע חוזר

כיתה ז׳ · Python A · **עד שהמשימה נגמרת: לולאת while**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> הלולאה `while` חוזרת כל עוד התנאי `True`. משהו בתוך הלולאה חייב לקרב אותה לסיום.

## דף עזר

```python
count = 1
while count <= 5:
    print(count)
    count = count + 1
print("Finished")
```

<div dir="rtl">

- ערך התחלה — לפני הלולאה.
- תנאי — נבדק לפני כל סבב.
- עדכון — בתוך הלולאה, מקרב לסיום.
- מספר הסבבים ידוע מראש ← `for`. הסיום תלוי בתנאי ← `while`.

</div>
