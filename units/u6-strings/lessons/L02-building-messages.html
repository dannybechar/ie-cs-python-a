קוראים ← חוזים ← מריצים ← בודקים ← מתקנים

IMPORTANT

אותו אופרטור עושה עבודה אחרת לפי הטיפוס: 5 + 5 הוא 10, אבל "5" + "5" הוא "55".

דף עזר

ביטוי תוצאה
5 + 5 10
"5" + "5" 55
"ha" * 3 hahaha
"a" in "cat" True
"x" not in "cat" True
str(5) + "5" 55 
for char in "code":
    print(char)

result = ""
for char in "a b":
    if char != " ":
        result = result + char
print(result)
  • הסימן + מחבר מחרוזות, בלי רווח. את הרווח מוסיפים לבד: first + " " + last.
  • הסימן * חוזר על מחרוזת כמה פעמים (בבחינה: כפל מחרוזות). הסימן + נקרא שם שרשור מחרוזות.
  • האופרטור in מחזיר True או False. אותיות גדולות וקטנות שונות זו מזו. not in הפוך ממנו.
  • הפונקציה str() הופכת מספר למחרוזת: str(5) + "5" נותן 55.
  • לולאת for על מחרוזת נותנת תו אחד בכל סבב.
  • בונים מחרוזת חדשה כמו שסופרים: מתחילים ב-result = "" ובכל סבב result = result + char. הכתיבה result += char פירושה אותו דבר (קוראים אותה, אבל כותבים את הצורה הארוכה).
  • מילון: פונקציה שכתבתם נקראת בבחינה פעולה.

1. חימום: למה 23?

פתחו את Operators_Starter.py:

# Warm-up: 2 + 3 should be 5.
# Why does it print 23?
a = input("First number: ")
b = input("Second number: ")
print("Sum:", a + b)

הריצו עם 2 ו-3, הסבירו את התוצאה, ותקנו.

2. משימה 1: ברכה והסרת רווחים

  1. כתבו פונקציה בשם greeting() שקולטת שם פרטי ושם משפחה ומדפיסה Hello Dana Levi.
  2. כתבו פונקציה בשם remove_spaces() שקולטת משפט ובונה מחרוזת חדשה בלי הרווחים. התחילו ב-result = "". בדקו עם a b c: abc.

3. משימה 2: כמה פעמים?

כתבו פונקציה בשם count_letter() שקולטת מילה ואות, וסופרת בעזרת לולאה, תנאי ומונה כמה פעמים האות מופיעה.

בדקו עם banana ו-a: a appears 3 times.

4. משימה 3: כוכביות

כתבו פונקציה בשם stars() שקולטת מילה ובונה מחרוזת חדשה: כל אות באינדקס זוגי הופכת ל-*, והשאר נשארות. השתמשו ב-for i in range(len(text)): ובתנאי i % 2 == 0.

בדקו עם rover: *o*e*.

5. משימה 4: בודקים כתובת מייל

כתבו פונקציה בשם check_mail() שקולטת כתובת. היא תקינה כשאין בה רווח ויש בה @. השתמשו ב-not in וב-in. היא מדפיסה Valid או Invalid.

בדקו עם dana@mail.com, עם dana mail.com ועם danamail.com.

6. משימה 5: בודקים סיסמה

כתבו פונקציה בשם password_check() שקולטת סיסמה ומדפיסה Contains ! אם יש בה !, ו-Contains 7 אם יש בה 7. אם יש את שניהם, היא מדפיסה גם Strong password.

בדקו עם hello!, עם abc7 ועם go!7.

אתגרים (לא חובה)

  • banner(): קולטת מילה ומדפיסה אותה בתוך מסגרת של כוכבים. רמז: אורך שורת הכוכבים הוא len(word) + 4.
  • every_third(): בונה מחרוזת מכל אות שלישית, בעזרת range(0, len(text), 3).
