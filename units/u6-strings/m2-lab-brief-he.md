# יחידה 6.2 – מחרוזות

כיתה ז׳ · Python A · **בונים הודעות: שרשור, כפל מחרוזות ו-in**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> אותו אופרטור עושה עבודה אחרת לפי הטיפוס: `5 + 5` הוא 10, אבל `"5" + "5"` הוא `"55"`.

## דף עזר

| ביטוי | תוצאה |
|---|---|
| `5 + 5` | `10` |
| `"5" + "5"` | `55` |
| `"ha" * 3` | `hahaha` |
| `"a" in "cat"` | `True` |
| `"x" not in "cat"` | `True` |
| `str(5) + "5"` | `55` |

```python
for char in "code":
    print(char)

result = ""
for char in "a b":
    if char != " ":
        result = result + char
print(result)
```

<div dir="rtl">

- הסימן `+` מחבר מחרוזות, בלי רווח. את הרווח מוסיפים לבד: `first + " " + last`.
- הסימן `*` חוזר על מחרוזת כמה פעמים (בבחינה: כפל מחרוזות). הסימן `+` נקרא שם שרשור מחרוזות.
- האופרטור `in` מחזיר `True` או `False`. אותיות גדולות וקטנות שונות זו מזו. `not in` הפוך ממנו.
- הפונקציה `str()` הופכת מספר למחרוזת: `str(5) + "5"` נותן `55`.
- לולאת `for` על מחרוזת נותנת תו אחד בכל סבב.
- בונים מחרוזת חדשה כמו שסופרים: מתחילים ב-`result = ""` ובכל סבב `result = result + char`. הכתיבה `result += char` פירושה אותו דבר (קוראים אותה, אבל כותבים את הצורה הארוכה).
- מילון: פונקציה שכתבתם נקראת בבחינה **פעולה**.

</div>
