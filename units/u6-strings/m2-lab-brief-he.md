# יחידה 6.2 – מחרוזות

כיתה ז׳ · Python A · **בונים הודעות: שרשור, שכפול ו-in**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> אותו אופרטור עושה עבודה אחרת לפי הטיפוס: `5 + 5` הוא 10, אבל `"5" + "5"` הוא `"55"`.

## דף עזר

| ביטוי | תוצאה |
|---|---|
| `5 + 5` | `10` |
| `"5" + "5"` | `55` |
| `"ha" * 3` | `hahaha` |
| `"a" in "cat"` | `True` |

```python
for char in "code":
    print(char)
```

<div dir="rtl">

- הסימן `+` מחבר מחרוזות, בלי רווח. את הרווח מוסיפים לבד: `first + " " + last`.
- הסימן `*` חוזר על מחרוזת כמה פעמים.
- האופרטור `in` מחזיר `True` או `False`. אותיות גדולות וקטנות שונות זו מזו.
- לולאת `for` על מחרוזת נותנת תו אחד בכל סבב.

</div>
