# Unit 6 — Strings

**8h = 2 Theory + 6 Labs = 4 double meetings**
Source: [`python-a.pdf`](../../../docs/ministry-source/python-a.pdf) Unit 6. Framing: [`../../../docs/annual-strategy.md`](../../../docs/annual-strategy.md).

**Build status:** ❌ not started.

## Meeting 1 — Knowledge + Lab
- `str`.
- empty string.
- indexing.
- `len`.
- `+`, `*`, `in`.

## Meeting 2 — Knowledge + Lab
- slicing: start / end / step.
- key operations: `find`, `upper`, `lower`, `count`, `startswith`,
  `endswith`, `isalpha`, `isnumeric`, `replace`.

## Meeting 3 — Lab + Lab
- string manipulation problems.
- combine indexing, slicing and methods.
- read/trace/modify exercises.

## Meeting 4 — Lab + Lab
- integrated text-processing challenge.
- assessment task requiring processing of an input string.

## Exit criteria
The student can access characters, slice a string, use key operations, and
solve a text-processing problem.

## Enrichment
- more complex text-processing tasks with the same tools.
