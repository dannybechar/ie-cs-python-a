משתנה תפקיד אתחול עדכון
count מונה 0 count = count + 1
total צובר 0 total = total + value (מקוצר: total += value)
minimum מינימום הערך הראשון אם value < minimum
maximum מקסימום הערך הראשון אם value > maximum 
number = int(input("Number: "))
maximum = number
for i in range(4):
    number = int(input("Number: "))
    if number > maximum:
        maximum = number
print("Max:", maximum)

1. חימום: למה 5?

פתחו את Accumulators_Starter.py:

# Warm-up: the total should be 15. Why is it 5?
for value in range(1, 6):
    total = 0
    total = total + value
print("Total:", total)

2. משימה 1: תרומות

כתבו פונקציה (בבחינה: פעולה) בשם donations() שקולטת תרומות עד שהתרומה היא 0 או שלילית (זה סימן העצירה, לא תרומה). הדפיסו כמה תורמים היו ומה סכום התרומות.

בדקו עם 50, 20, 100, 0. התשובה: 3 תורמים, סכום 170. בדקו גם כשהערך הראשון הוא 0.
