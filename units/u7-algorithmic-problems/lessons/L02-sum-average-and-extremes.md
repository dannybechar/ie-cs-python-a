## דף עזר

| משתנה | תפקיד | אתחול | עדכון |
|---|---|---|---|
| `count` | מונה | 0 | `count = count + 1` |
| `total` | צובר | 0 | `total = total + value` (מקוצר: `total += value`) |
| `minimum` | מינימום | הערך הראשון | אם `value < minimum` |
| `maximum` | מקסימום | הערך הראשון | אם `value > maximum` |

```python
number = int(input("Number: "))
maximum = number
for i in range(4):
    number = int(input("Number: "))
    if number > maximum:
        maximum = number
print("Max:", maximum)
```

<div dir="rtl">

- ממוצע = `total / count`.
- לולאת `while` עם ערך עצירה: קולטים ערך לפני הלולאה, ובסוף כל סבב קולטים את הבא.
- את הערך הראשון קולטים לפני הלולאה, ולכן הלולאה חוזרת פעם אחת פחות.

</div>
