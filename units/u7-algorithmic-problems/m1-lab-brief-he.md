# יחידה 7.1 – בעיות אלגוריתמיות

כיתה ז׳ · Python A · **כמה פעמים? תבנית המונה**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> מונה עונה על השאלה "כמה פעמים?": הוא מתחיל ב-0 לפני הלולאה, וגדל ב-1 רק כשהאירוע קורה.

## דף עזר

```python
count = 0
for number in range(1, 21):
    if number % 3 == 0:
        count = count + 1
print("Count:", count)
```

<div dir="rtl">

- אתחול: `count = 0` לפני הלולאה.
- עדכון: `count = count + 1` בתוך ה-`if`, רק כשהאירוע קורה.
- הדפסה: פעם אחת, אחרי הלולאה.
- שתי שאלות ← שני מונים.

</div>
