## דף עזר

```python
def show_header():
    print("SHOP")


def show_menu():
    print("1. Products")
    print("2. Cart")


def main():
    show_header()
    show_menu()


main()
```

<div dir="rtl">

- הסדר נקבע לפי הזימונים, לא לפי סדר ההגדרות.
- פונקציה בלי פרמטרים יכולה לקלוט קלט בתוך הגוף שלה.
- הזימון נכתב מחוץ להגדרה — לא מוזח מתחתיה.
- `main` הוא שם שאנחנו בוחרים. בחומרי משרד החינוך קוראים לפונקציה גם **פעולה**, ולרוב מזמנים אותה ישר אחרי ההגדרה, בלי `main()`. שתי הדרכים נכונות.

</div>
