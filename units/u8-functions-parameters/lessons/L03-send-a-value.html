קוראים ← חוזים ← מריצים ← בודקים ← מתקנים

IMPORTANT

פרמטר הוא משתנה בהגדרה. ארגומנט הוא הערך שהזימון שולח אליו. בחומרי משרד החינוך ובמבחן קוראים לשניהם "פרמטר" או "ערך", ולפונקציה קוראים גם "פעולה".

דף עזר

def greet(name):
    print("Hello", name)


greet("Dana")
greet("Noam")
דרך לקבל ערך מאיפה מגיע הערך דוגמה
פרמטר מהזימון greet("Dana")
קלט מהמשתמש, בזמן הריצה name = input("Name: ")
  • בכל זימון הפרמטר מקבל ערך חדש, והגוף נשאר אותו גוף.
  • הסדר חשוב: הארגומנט הראשון הולך לפרמטר הראשון.
  • ארגומנט אחד לכל פרמטר — אחרת מתקבלת השגיאה TypeError.

פונקציה שמחזירה ערך:

def add(x, y):
    return x + y


total = add(5, 7)
print(total)
print(add(add(5, 6), add(1, 2)))
  • print מציגה על המסך. return מחזירה את הערך למי שזימן, ושם אפשר להדפיס אותו, לשמור אותו במשתנה או להשתמש בו בעוד חישוב.
  • גם input(), int() ו-randint() מחזירות ערך.

2. מעבר מקלט לפרמטרים: pool(times, price)

קחו את הפונקציה pool() מ-8.2, שקלטה את times ואת price בתוך הגוף. כתבו אותה מחדש כ-pool(times, price), כך שהמספרים מגיעים מהזימון: pool(3, 25).

3. משימה 1: הודעה חוזרת

כתבו פונקציה בשם repeat_message(message, times) שמדפיסה את ההודעה times פעמים, בעזרת לולאה. זמנו: repeat_message("Go", 4).

4. משימה 2: ריבוע בכל גודל

כתבו פונקציה בשם draw_square(size). זמנו אותה שלוש פעמים: 50, 100 ו-150.

5. משימה 3: פונקציות שמחזירות ערך

  1. כתבו פונקציה בשם absolute_value(number) שמחזירה את המספר בלי סימן מינוס. הדפיסו מחוץ לפונקציה: print(absolute_value(-7)) ו-print(absolute_value(4)).
  2. כתבו פונקציה בשם sign_text(number) שמחזירה את המחרוזת "positive", "negative" או "zero". הדפיסו מחוץ לפונקציה את התוצאה עבור 5, ‎-3 ו-0.

הפונקציות מחזירות ולא מדפיסות: ההדפסה נמצאת בשורת הזימון.

רשות (לבית): draw_rectangle(width, height) — פעמיים: רוחב, פנייה, גובה, פנייה. זמנו draw_rectangle(140, 70) ואחר כך draw_rectangle(70, 140). מה השתנה? וגם תרגילי הפונקציות המחזירות בקובץ Extra_Practice_U8.md.
