IMPORTANT

משתנה שנוצר בתוך פונקציה קיים רק בה. כדי לשנות משתנה חיצוני בתוך פונקציה, מצהירים עליו global.

דף עזר

score = 0


def add_point():
    global score
    score = score + 1


add_point()
add_point()
print(score)
משתנה מקומי משתנה global
איפה נוצר בתוך פונקציה מחוץ לכל הפונקציות
איפה מוכר רק בפונקציה שלו בכל התוכנית
שינוי בתוך פונקציה השמה רגילה צריך קודם global
  • לקרוא משתנה חיצוני אפשר בלי global. לשנות אותו — רק עם global.
  • ערכים שהפונקציה צריכה — שולחים בפרמטרים. את global שומרים למצב משותף, כמו מונה.
  • score += 1 זו דרך קצרה לכתוב score = score + 1. שתיהן מופיעות בחומרי משרד החינוך ובמבחן; אצלנו כותבים את הצורה הארוכה.

2. גשר: sum_numbers(num1, num2)

  1. כתבו פונקציה בשם sum_numbers(num1, num2) שמחשבת את סכום כל המספרים השלמים מ-num1 עד num2 (כולל), בעזרת לולאה ומשתנה total, ומדפיסה אותו בתוך הפונקציה. זמנו sum_numbers(1, 5).
  2. שנו אותה כך שתחזיר את total במקום להדפיס, והדפיסו מחוץ לפונקציה: print(sum_numbers(1, 5)).
