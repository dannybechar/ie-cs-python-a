# יחידה 8.1 – פונקציות עם פרמטרים

כיתה ז׳ · Python A · **למה פונקציות? הגדרה, זימון ופירוק תוכנית**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> פונקציה נותנת שם לקטע קוד: כותבים אותו פעם אחת, ומזמנים אותו בכל מקום שצריך.

## דף עזר

```python
def show_line():
    print("********")


show_line()
print("Welcome")
show_line()
```

| חלק | תחביר | תפקיד |
|---|---|---|
| הגדרה | `def show_line():` | יוצרת את הפעולה — עוד לא מריצה |
| גוף | שורות מוזחות | מה שירוץ |
| זימון | `show_line()` | מריץ את הגוף עכשיו |

<div dir="rtl">

- קודם מגדירים, ורק אחר כך מזמנים.
- הפונקציות שלנו מבצעות פעולה (הדפסה או ציור) ואינן מחזירות ערך.

</div>
