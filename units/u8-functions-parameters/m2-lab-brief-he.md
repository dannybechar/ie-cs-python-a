## דף עזר

```python
def show_header():
    print("SHOP")


def show_menu():
    print("1. Products")
    print("2. Cart")


def main():
    show_header()
    show_menu()


main()
```

<div dir="rtl">

- הסדר נקבע לפי הזימונים, לא לפי סדר ההגדרות.

- הזימון נכתב מחוץ להגדרה — לא מוזח מתחתיה.

</div>
