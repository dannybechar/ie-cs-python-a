קוראים ← חוזים ← מריצים ← בודקים ← מתקנים

IMPORTANT

הפקודה turtle.listen() מפעילה האזנה למקלדת. הפקודה turtle.onkey(function, "Up") מחברת מקש לפונקציית תגובה.

דף עזר

def up():
    turtle.sety(turtle.ycor() + 20)


turtle.listen()
turtle.onkey(up, "Up")
  • מקש לא שולח x ו-y, ולכן לפונקציית התגובה אין פרמטרים.
  • בבחינה כותבים onkeypress (או onkeyrelease — כשמרפים מהמקש) במקום onkey, על אובייקט המסך: screen.onkeypress(...).
  • מקש לא מגיב? בודקים: יש turtle.listen() · שם המקש מדויק ("Up", "space") · שם הפונקציה בלי סוגריים.
  • גבול: מחשבים קודם את המקום החדש, וזזים רק אם הוא בתוך הגבול.

1. חימום: שום דבר לא קורה

פתחו את Keys_Starter.py, הריצו ולחצו על החץ למעלה:

# Warm-up: press the Up arrow. Why does nothing happen?
import turtle


def up():
    turtle.sety(turtle.ycor() + 20)


turtle.shape("turtle")
turtle.onkey(up, "Up")
turtle.done()

2. משימה 1: ארבעה כיוונים, עם גבולות

כתבו up(), down(), left(), right(). שמאלה וימינה הצב נשאר בין -200 ל-200.

3. משימה 2: עט במקש רווח

כתבו פונקציה בשם toggle_pen(): רווח מחליף בין ציור לתנועה בלי ציור (pen_on = not pen_on).

4. משימה 3 (אתגר): מגיעים למטרה

ציירו נקודה אדומה ב-(160, 100). אחרי כל תזוזה בדקו turtle.distance(160, 100) < 20, והדפיסו Win.
